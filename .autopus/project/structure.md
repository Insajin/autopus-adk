## Package Boundaries

| Boundary | Responsibility |
|---|---|
| `internal/cli` | User commands, orchestration, lifecycle ordering, doctor output |
| `pkg/adapter` | Platform-specific preparation, validation, transaction, cleanup |
| `pkg/content` | Canonical content compilation and cross-platform normalization |
| `pkg/config` | Secure config loading, defaults, migration, persistence |
| `pkg/setup` | Repository scanning and generated project-context documents |
| `pkg/promptlayer` | Required-context integrity and body-free receipts |
| `pkg/orchestra` | Provider transport and result aggregation |
| `pkg/worker` | Long-running worker/control-plane behavior |

|---|---|
| Claude Code | `.claude/skills/<name>/SKILL.md`, `.claude/agents/`, `.claude/workflows/`, `.claude/settings.json` |
| Codex | `.codex/skills/codex-<name>/SKILL.md`, `.codex/agents/`, `.codex/hooks.json`, `.codex/config.toml` |
| OpenCode | `.opencode/`, `.agents/skills/`, `opencode.json` |
| OMP | `.omp/skills/<name>/SKILL.md`, `.omp/commands/`, `.omp/agents/`, flat `.omp/rules/autopus-*.md` |
| Antigravity | `.gemini/`, `GEMINI.md` |

Generated platform files are projections, not canonical sources. Change `content/`, `templates/`, or the relevant adapter, then run `go run ./cmd/generate-templates` and `auto update`.

## Maintenance Rules

- Source files stay at or below 300 lines.
- Generated surfaces must be regenerated from canonical sources.
- Platform manifests own only exact generated paths; user files in shared native roots remain untouched.
- `structure.md` targets 18,000 bytes and must remain below the 20,000-byte doctor soft cap.
