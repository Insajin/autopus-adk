# auto-map

## OMP Invocation

- `/auto map ...`
- `/auto-map ...`
- Load detail skill `auto-map` for either entrypoint.

## 실행 계약

코드베이스 분석 — 구조, 엔트리포인트, 의존성을 빠르게 요약합니다

1. 대상 디렉터리와 전달된 인자를 확인합니다.
2. Workspace tools로 구조, entrypoint, 의존성을 분석합니다.
3. 핵심 파일과 다음 액션을 요약합니다.
